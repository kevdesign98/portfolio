ValApp: Performance Analysis

Ho sviluppato ValApp, una Single Page Application (SPA) dedicata all'analisi delle performance per i giocatori di Valorant.

La sfida principale è stata gestire l'integrità del data binding con dati dinamici, spesso incompleti o oscurati (Streamer Mode) dalle API ufficiali.

Key Highlights
  • ⚡ Data Persistence: Implementazione di logica di tracciamento via PUUID per garantire un'associazione corretta dei match, anche con profili privati.
  • ⚡ Real-time Analytics: Algoritmi per il calcolo istantaneo di K/D Ratio, Win Rate e Accuracy (HS%) partendo da payload JSON complessi.
  • ⚡ Clean UI: Interfaccia reattiva focalizzata sulla data visualization per rendere immediata la lettura delle statistiche di combattimento.
  • ⚡ Tech Stack: Angular, TypeScript, RxJS, Tailwind CSS, integrazione REST API e Google Gemini.
